# Floating ToDo App

悬浮在桌面边上的 ToDo 应用，具有水玻璃（Glassmorphism）风格界面。

## 功能特性

- ✅ 悬浮在桌面右侧边缘
- ✅ 水玻璃风格界面（毛玻璃效果）
- ✅ 添加、删除、完成待办事项
- ✅ 设置日程提醒（系统通知）
- ✅ 播放指定路径的音乐
- ✅ 任务筛选（全部/进行中/已完成）
- ✅ 数据本地持久化存储
- ✅ 系统托盘图标

## 安装和运行

### 前提条件

- Node.js (建议 v16 或更高版本)
- npm

### 安装步骤

1. 进入项目目录：
   ```bash
   cd FloatingTodoApp
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 创建图标文件：
   - 在项目根目录放置一个 `icon.png` 文件（建议 256x256 像素）

4. 启动应用：
   ```bash
   npm start
   ```

## 使用说明

### 添加待办事项
1. 在输入框中输入任务内容
2. 可选择设置提醒时间
3. 可选择输入音乐文件路径（支持本地音乐文件）
4. 点击"添加"按钮或按回车键

### 管理待办事项
- 点击圆形复选框标记任务完成
- 点击 🗑️ 按钮删除任务
- 点击 🎵 播放关联的音乐

### 音乐播放
- 支持本地音乐文件路径（如：`C:\Music\song.mp3`）
- 底部播放控制栏可控制播放/暂停/停止

### 窗口操作
- 拖动顶部标题栏可移动窗口
- 点击 − 最小化
- 点击 × 关闭应用
- 可通过系统托盘图标重新打开

## 技术栈

- Electron - 桌面应用框架
- HTML/CSS/JavaScript - 前端界面
- Glassmorphism - 水玻璃设计风格

## 自定义

### 修改窗口大小和位置
编辑 `main.js` 中的窗口配置：
```javascript
mainWindow = new BrowserWindow({
  width: 320,    // 窗口宽度
  height: 500,   // 窗口高度
  x: width - 340, // X坐标（右侧）
  y: Math.floor(height / 2) - 250, // Y坐标（居中）
  // ...
});
```

### 修改界面颜色
编辑 `styles.css` 中的颜色变量和渐变色。

## 注意事项

1. 首次运行需要先安装依赖：`npm install`
2. 需要准备一个 `icon.png` 图标文件
3. 音乐播放功能仅支持本地文件路径
4. 提醒功能依赖系统通知权限
