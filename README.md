# 悬浮待办清单 (Floating Todo)

一款简约、美观的桌面悬浮待办事项软件。支持半透明玻璃拟态、颜色自定义，并且非常轻量。

## ✨ 功能特点

- **桌面悬浮胶囊**：默认只显示一个小胶囊，不占用桌面空间。
- **展开式清单**：点击胶囊展开完整待办列表。
- **个性化设置**：
  - 右键菜单调节 **透明度** (20% - 100%)。
  - 右键菜单调节 **主题色** (任意颜色)。
- **数据持久化**：自动保存即使关闭程序也不会丢失数据。

## 🚀 如何获取软件 (.exe)

由于你没有安装编译环境，可以使用 **GitHub Actions** 在线生成软件：

1. **上传代码**：将本文件夹内的所有文件上传到你自己的 GitHub 仓库。
2. **触发构建**：
   - 如果你直接 Push 代码，构建会自动开始。
   - 或者去仓库的 "Actions" 标签页，在左侧选择 "Build Windows App"，然后点击 "Run workflow"。
3. **下载软件**：
   - 等待构建完成（约 2-3 分钟，显示绿色对勾）。
   - 点击该次构建记录。
   - 在页面底部的 **Artifacts** 区域，点击 **FloatingTodo-Executable** 下载。
   - 解压下载的 zip 包，里面就是 `FloatingTodo.exe`，直接双击运行即可。

## 🛠️ 本地开发 (可选)

如果你想在本地运行 (需要 Python 3.10+):

```bash
pip install -r requirements.txt
python main.py
```
